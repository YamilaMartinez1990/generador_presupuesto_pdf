# generador_presupuesto_pdf
Script en Python para automatizar la creacion de presupuestos en PDF con FPDF y Google Colab

# 📄 Generador Automático de Presupuestos en PDF

Este proyecto es un script automatizado desarrollado en **Python** diseñado para agilizar y estandarizar la creación de presupuestos comerciales. Permite recolectar datos comerciales mediante consola y exportar un documento PDF con maquetación profesional sobre una plantilla institucional.

## 🛠️ Tecnologías Utilizadas
* **Python 3**
* **FPDF**: Librería nativa para la gestión, posicionamiento y diseño de documentos PDF.
* **Google Colab & Google Drive**: Implementación de entorno en la nube para el almacenamiento permanente de assets y distribución segura.

## 🚀 Características del Desarrollo
* **Interactividad Dinámica:** Consola interactiva para la captura de datos (descripción del proyecto, horas estimadas, valor por hora y tiempos de entrega).
* **Lógica de Cálculo Automática:** Computación aritmética en tiempo real para determinar el valor total del servicio de forma exacta.
* **Conexión Directa a la Nube:** Integración nativa con sistemas de archivos en la nube mediante almacenamiento virtualizado, garantizando la persistencia de la plantilla base y del PDF generado.

## 📂 Estructura del Repositorio
* `proyecto_pdf.ipynb`: Cuaderno principal con el código fuente del programa.
* `Template.png`: Archivo de diseño gráfico utilizado como fondo del presupuesto.
Adicional: `Presupuesto.pdf`: Archivo PDF de muestra
